# Knowledge and Learning

Do not accumulate one giant learning file.

When work reveals reusable knowledge, promote it to the smallest durable destination:

- violated invariant → regression test;
- lasting architecture decision → ADR/design doc;
- reusable procedure → local skill/workflow;
- coding convention → coding rule/tooling;
- operator-visible incident → incident/problem record;
- temporary task detail → task/spec evidence only.

A lesson is mature when it changes future behavior without requiring agents to reread historical sessions.

Remove stale/conflicting guidance when a newer rule supersedes it.
